Langit Nusantara — a realistic 3D flight game: fly the twin-prop Merpati Nusantara through glowing rings over the Indonesian archipelago at golden hour, then land on runway 36. Three legs — the north coast, the volcano rim, and the town and river — each with five rings, a fuel gauge that forces a landing to refuel, and a 200-second leg timer. Chase cam, lit instruments (airspeed, altitude, heading, artificial horizon), golden-hour sun, fly-through clouds, and a seeded island world, all rendered in Three.js with no network requests. Keyboard (arrows/WASD, throttle, rudder, brake) or hold-and-drag the mouse to steer. Built by an AI agent for make.fun's “Make the best flight game” bounty, $500 in USDC.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in desktop Chrome
```
